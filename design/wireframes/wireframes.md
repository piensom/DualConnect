**Key Design Elements:**
- **Simple language** (B1 level German/English)
- **Visual explanations** (diagrams, timelines)
- **FAQ accordion** for quick answers
- **Real testimonials** for trust-building
- **Multilingual support** emphasized
- **Large, clear CTAs** for next steps
- **Reassuring tone** addressing common parental concerns

---

## Design Principles Applied

### 1. **Accessibility**
- High contrast text
- Large font sizes (minimum 16px body text)
- Clear visual hierarchy
- Icon + text labels (never icon-only)
- Keyboard navigable

### 2. **Parent-Friendly Design**
- Avoid jargon
- Use metaphors and comparisons
- Visual storytelling
- Reassuring, warm tone
- Multilingual content

### 3. **Mobile-First**
- Stacked layouts for small screens
- Touch-friendly tap targets (44px minimum)
- Collapsible sections
- Hamburger menu for navigation
- Swipeable cards

### 4. **Performance**
- Minimal imagery
- Lazy loading for images
- Efficient filtering (client-side where possible)
- Fast page loads

### 5. **Trust & Credibility**
- Real testimonials with photos
- Partner logos
- Clear contact information
- Transparent information
- Government/institutional branding

## Color & Typography Guidelines

### Color Palette
```
Primary Blue:    #0066CC (trust, professionalism)
Secondary Green: #28A745 (success, growth)
Accent Orange:   #FF6B35 (warmth, action)
Neutral Gray:    #6C757D (text, borders)
Light Gray:      #F8F9FA (backgrounds)
White:           #FFFFFF (cards, content areas)
```

### Typography
```
Headings: "Inter" or "Open Sans" (sans-serif, friendly)
Body: "Inter" or "Roboto" (highly readable)
Size Scale: 14px, 16px, 18px, 24px, 32px, 48px
Line Height: 1.5 for body, 1.2 for headings
```

### Icons
- Use simple, universally recognized icons
- Material Icons or Font Awesome
- Always pair with text labels
