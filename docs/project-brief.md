# Dual Connect - Project Brief

## Project Summary

**Dual Connect** is an innovative web-based platform designed to bridge the information gap for international families seeking dual education and dual study opportunities in Germany. This MVP (Minimum Viable Product) serves as both a functional prototype and a comprehensive training project for vocational students.

## Problem Statement

International families from third countries face significant challenges when navigating Germany's dual education system:
- Scattered information across multiple platforms and languages
- Complex terminology and bureaucratic processes
- Limited understanding of dual education vs. traditional academic paths
- Difficulty identifying suitable programs, companies, and funding options
- Language barriers preventing effective communication with stakeholders

## Solution

A centralized, user-friendly platform that:
- **Simplifies search and discovery** of dual education programs
- **Translates complex processes** into parent-friendly language
- **Connects families directly** with relevant stakeholders (IHK, universities, companies)
- **Provides comprehensive resources** on requirements, funding, and application procedures

## Target Audience

**Primary Users:**
- International families with children aged 14-25 seeking vocational training or dual study programs
- Parents with limited German language proficiency
- Youth advisors and integration support workers

**Secondary Users:**
- Vocational schools and universities offering dual programs
- Companies providing Ausbildung positions
- IHK representatives and career counselors

## Project Scope (MVP)

### Core Features
1. **Search & Filter Interface**: Browse programs by industry, location, company, and requirements
2. **Parent Information Hub**: Simplified explanations of dual education system basics
3. **Program Profiles**: Detailed information on training programs and study opportunities
4. **Contact Directory**: Direct connections to IHK, universities, companies, and advisors
5. **Resource Library**: Downloadable guides, checklists, and application templates

### Technical Deliverables
- Functional website prototype (HTML/CSS/JavaScript)
- Database schema with 5+ core tables and relationships
- 10 sample data entries per table (50+ total records)
- Wireframes for 4 key pages (landing, search, program detail, parent info)
- ER diagram with data model documentation

### Documentation Deliverables
- Project brief (this document)
- SWOT analysis of competing platforms
- Team roles and responsibilities document
- 6-block development timeline
- Presentation materials (5-10 minute overview)
- Usability test plan and feedback checklist

## Success Criteria

### User Experience
- Families can find relevant programs within 3 clicks
- Information is accessible at B1 German language level
- Parent section uses simple, jargon-free language
- Mobile-responsive design for accessibility

### Educational Value
- Demonstrates full-stack project planning and execution
- Showcases collaborative team development
- Provides hands-on experience with database design, UX prototyping, and web development
- Suitable for handoff between student teams across 6 project blocks

### Technical Quality
- Clean, semantic HTML5 markup
- Responsive CSS design
- Functional search/filter with sample data
- Well-documented code and database schema

## Project Timeline

**Duration**: 30-36 weeks (6 blocks × 5-6 weeks)
**Team Size**: 5-7 vocational students
**Time Commitment**: 2 hours/week per student

### Block Overview
1. **Kickoff & Research** (Weeks 1-6): Market analysis, requirements gathering
2. **Concept & Data** (Weeks 7-12): Database design, content structure
3. **UX Prototype** (Weeks 13-18): Wireframes, user flows, design system
4. **Data Integration** (Weeks 19-24): Sample data, import/export logic
5. **MVP Testing** (Weeks 25-30): Usability tests, feedback iteration
6. **Finalization** (Weeks 31-36): Final report, presentation, lessons learned
